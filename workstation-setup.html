Installation Order

  1. Git for Windows - Install first for version control
  2. WPILib - Includes VS Code and Java
  3. FRC Game Tools - Includes Driver Station and roboRIO imaging tool
  4. Elastic Dashboard - Primary driver & pit dashboard
  5. Phoenix Tuner X - For CTRE devices (drivetrain & mechanism motors)
  6. REV Hardware Client - For REV devices

Git Installation

  1. Download 64-bit Git for Windows Setup from git-scm.com/download/win
  2. Run the installer
  3. Accept all default options (click Next through all screens)
  4. Complete installation

Verify: Open Command Prompt and type git --version. Should show version number.

WPILib Installation

  1. Download WPILib_Windows-2025.x.x.iso from GitHub releases
  2. Double-click the .iso file to mount it (Windows 10/11 opens it automatically)
  3. Run WPILibInstaller.exe
  4. Select "Install for this User" (recommended) or "Install for all Users"
  5. Select "Download VS Code" when prompted
  6. Wait for installation to complete

Verify: Open "WPILib VS Code" from Start menu. Type Ctrl+Shift+P and search "WPILib" - you should see WPILib commands.

FRC Game Tools (Driver Station)

  1. Download NI FRC Game Tools from NI Downloads
  2. Run installer as Administrator
  3. Accept license agreements
  4. Restart when prompted

Verify: Open "FRC Driver Station" from Start menu. Status lights should appear (will show "No Robot Communication" until connected).

Elastic Dashboard Setup

  1. Download Elastic-Windows-x64-installer.exe from GitHub releases and run the installer
  2. Open Elastic and click Settings (gear icon) to configure the NetworkTables (NT4) connection:
    • For Real Robot (WiFi / USB / Ethernet): Set Team Number / IP to 10413 (automatically connects to 10.104.13.2 on WiFi or 172.22.11.2 over USB)
    • For Laptop Simulation (./gradlew simulateJava): Set IP Address to 127.0.0.1 (localhost)
  3. Load the team dashboard layout via File > Open Layout (located in the root of the robot repository):
    • elastic-competition.json (Match Play): Single Match tab with Field view, RobotName, Auto Chooser, Alliance, Battery, Vision, Has Targets, and Shooter At Target
    • elastic-test.json (Pit, Practice & Calibration): 5 diagnostic tabs (Setup, Vision & Cal, Drive Style, Tuning, Auto Test)

Verify: When connected to the robot or simulation, the title bar shows Connected (NT4) and a notification toast appears on boot (e.g., [FUEL] initialized with 3 camera(s)).

Phoenix Tuner X

  1. Download from CTRE website or Microsoft Store
  2. Install and open Phoenix Tuner X
  3. Connect to robot via USB or WiFi (10.104.13.2)

Verify: With robot powered on and connected, devices should appear in the device list.

REV Hardware Client

  1. Download from REV Robotics website
  2. Run installer
  3. Connect SparkMax via USB-C to configure

Verify: Connect a SparkMax via USB. Device should appear in the client.

Verification Checklist

  • Git installed (git --version works in Command Prompt)
  • WPILib VS Code opens and shows WPILib commands
  • Can create a new WPILib project (Ctrl+Shift+P > "Create a new project")
  • Driver Station opens and shows interface
  • Elastic Dashboard opens, Team Number set to 10413, and elastic-competition.json / elastic-test.json layout loads
  • Phoenix Tuner X installed and opens
  • REV Hardware Client installed and opens

Troubleshooting

WPILib VS Code won't open

  • Reinstall WPILib using the installer
  • Make sure you're opening "WPILib VS Code", not regular VS Code

Driver Station shows "No Robot Communication"

  • Connect to robot WiFi (10.104.13.X network)
  • Or connect via USB to roboRIO
  • Check that robot is powered on

Phoenix Tuner can't find devices

  • Verify connection to robot network
  • Check that robot is powered and CAN bus is connected
  • Try connecting via USB to roboRIO
