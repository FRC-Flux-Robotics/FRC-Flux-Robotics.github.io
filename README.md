## Unified 2027 Software Suite (`v2027.1.0`)
- **`Flux-SystemCore-2027`:** Clean-sheet 2027 master robot codebase (`COMP_2027` / `PRACTICE_2027`).
- **`Flux-RoboRIO-2027`:** WPILib 2026 roboRIO 2.0 + CTRE CANivore robot codebase (`FUEL`, `CORAL`, `CHASSIS_3`) synced 1:1 on `frc.lib.*` via `BackTo2026`.
- **`FluxFig`:** Pure-Java 17 configuration engine, binary `.wpilog` codec (`FluxWpiLogCodec`), and 14-metric SystemCore watch parser (`FluxSystemSnapshot`).
- **`FluxTray`:** Driver Station system tray agent for 4-second `.fluxpkg.zip` SFTP switching, 5-slot rollback ring, and 3-headset audio capture.
- **`FluxProcessor`:** Post-match `.wpilog`/`.hoot`/audio analyzer, 3D `FuelSim` physics replayer, `--render-auto` student video generator, and MCP server.
