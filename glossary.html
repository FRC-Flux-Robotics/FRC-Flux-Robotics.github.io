FRC Glossary

Common terms explained for new team members

Driving & Controls

TermWhat It MeansLearn More
Field-Centric "Forward" always means toward the opposing alliance wall, regardless of which way the robot is facing. WPILib Coordinates
Robot-Centric "Forward" means the direction the robot's front is pointing. If the robot is sideways, pushing forward moves it sideways from your view. WPILib Coordinates
Strafe Moving sideways without rotating. Only swerve and mecanum drivetrains can do this. WPILib Drive Classes
Deadband A small zone around the joystick center that's ignored. Prevents drift when you're not touching the stick. WPILib Joysticks
Teleop The part of a match where drivers control the robot. Short for "teleoperated." WPILib Robot Program
Autonomous The first 15 seconds of a match where the robot runs pre-programmed actions with no driver input. WPILib Command-Based

Drivetrain Types

TermWhat It MeansLearn More
Swerve Drive Each wheel can spin AND rotate independently. Allows the robot to drive in any direction while facing any direction. WPILib Swerve
Tank Drive Wheels on left and right sides. Turn by running sides at different speeds. Simple but can't strafe. WPILib Differential
Mecanum Drive Special angled rollers on wheels allow strafing. Simpler than swerve but less pushing power. WPILib Mecanum
Swerve Module One corner of a swerve drivetrain. Contains a drive motor (spins wheel) and steer motor (rotates wheel direction). WPILib Swerve

Hardware Components

TermWhat It MeansLearn More
RoboRIO The robot's brain. A small computer from NI that runs your code and connects to all motors and sensors. WPILib RoboRIO
Motor Controller Electronics between the RoboRIO and a motor. Takes commands and delivers the right power. WPILib Motors
TalonFX A motor controller from CTRE built into Falcon 500 and Kraken motors. Used in our drivetrain. CTRE TalonFX
SparkMax A motor controller from REV Robotics. Used with NEO motors. We use these for mechanisms. REV SparkMax
CAN Bus A single wire connecting all motor controllers and sensors in a chain. Devices share the wire and take turns talking. WPILib CAN Wiring
CAN ID A unique number (0-62) assigned to each device on the CAN bus. Like a mailing address for the RoboRIO. WPILib CAN Wiring
CANcoder A sensor from CTRE that measures absolute rotation. Knows swerve wheel direction even after power off. CTRE CANcoder
Pigeon 2 An IMU (motion sensor) from CTRE. Measures which way the robot is facing. Required for field-centric driving. CTRE Pigeon 2
IMU Inertial Measurement Unit. A sensor that detects rotation and acceleration to tell which way the robot is pointing. WPILib Gyros
Encoder A sensor that counts rotations. Used to measure motor position or wheel distance traveled. WPILib Encoders
Solenoid An electrically-controlled valve that lets air through. Used to extend/retract pneumatic cylinders. WPILib Pneumatics
Pneumatics Systems using compressed air to move things. Good for fast, strong motions like opening an intake arm. WPILib Pneumatics

Software Concepts

TermWhat It MeansLearn More
Subsystem Code that controls one part of the robot (drivetrain, elevator). Only one command can use a subsystem at a time. WPILib Subsystems
Command An action the robot can perform (drive forward, raise elevator). Commands use subsystems to do work. WPILib Commands
PID Proportional-Integral-Derivative. A formula that smoothly moves a motor to a target position. WPILib PID Intro
kP, kI, kD PID tuning values. kP = push toward target. kI = fix steady errors. kD = slow when approaching. WPILib PID Tuning
Feedforward Telling the motor roughly how much power it needs before PID kicks in. Makes control smoother. WPILib Feedforward
kS, kV, kA Feedforward values. kS = overcome friction. kV = power per velocity. kA = power per acceleration. WPILib Feedforward
Gear Ratio How many motor rotations per wheel rotation. Higher ratio = more torque, slower speed. WPILib Encoders
Current Limit Maximum amps a motor can draw. Protects motors from overheating and prevents brownouts. CTRE Current Limits
Brownout When battery voltage drops too low. The RoboRIO may disable motors to protect itself. WPILib Brownouts

Tools & Software

TermWhat It MeansLearn More
WPILib The official FRC programming library. Provides code for motors, sensors, and robot structure. WPILib Zero to Robot
Driver Station Laptop software that connects to and enables the robot. Required at competitions. WPILib Driver Station
Phoenix Tuner X Software to configure CTRE devices (TalonFX, CANcoder, Pigeon). Set CAN IDs and test motors. CTRE Tuner X
REV Hardware Client Software to configure REV devices (SparkMax). Set CAN IDs, current limits, update firmware. REV Hardware Client
Deploy Uploading code from laptop to RoboRIO. The robot runs whatever was last deployed. WPILib Deploying
Simulation Running robot code on your laptop without a real robot. Good for testing logic first. WPILib Simulation

Vision

TermWhat It MeansLearn More
AprilTag A black and white barcode on the field. Robots detect them with cameras to know their position. WPILib AprilTag
PhotonVision Free software on a coprocessor that detects AprilTags and game pieces for the robot. PhotonVision Docs
Pose Estimation Using AprilTags to calculate exactly where the robot is on the field. Helps autonomous accuracy. WPILib Pose Estimation

Competition Terms

TermWhat It MeansLearn More
Match A 2.5 minute game: 15 seconds autonomous + 2:15 teleop. You play 8-12 qual matches per event. FRC Game Manual
Alliance Your team of 3 robots (Red or Blue). You're randomly paired with different teams each match. FRC Game Manual
Pit Your team's workspace at competition. Where you fix and maintain the robot between matches. FRC Game Manual
Queue The waiting area before going on field. You must be there 2-3 matches before yours. FRC Game Manual
E-Stop Emergency Stop. Instantly kills all robot power. On our robot: press both controller bumpers. WPILib Driver Station

Common Abbreviations

AbbreviationMeaningLearn More
FRC FIRST Robotics Competition FIRST FRC
CAN Controller Area Network (the communication wire between devices) WPILib CAN
PWM Pulse Width Modulation (older motor control method, less common now) WPILib PWM
PDP / PDH Power Distribution Panel / Hub. Distributes battery power to all devices. WPILib Power
PCM / PH Pneumatics Control Module / Hub. Controls the compressed air system. WPILib Pneumatics
NEO A brushless motor from REV Robotics. Popular for mechanisms. REV NEO
CTRE Cross The Road Electronics. Makes TalonFX, Pigeon, CANcoder. CTRE Phoenix 6
REV REV Robotics. Makes SparkMax, NEO motors, sensors. REV Docs
