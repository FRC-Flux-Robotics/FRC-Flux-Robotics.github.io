Coral Robot Configuration

FRC Team 10413 FLUX Robotics - 2025 Season - Elevator Mechanism Robot

Overview

The Coral robot is configured for the Elevator mechanism, designed to score Coral game pieces. It uses a swerve drivetrain with an elevator and tray system for game piece manipulation.
